# g-patcher

Лечит геоблок в Antigravity CLI, Antigravity 2.0 и IDE, когда Google плюется в консоль ошибкой:

```text
Eligibility check failed: Your current account is not eligible for Antigravity, because it is not currently available in your location.
```

Главная фишка — **один раз поставил и забыл**. Патчер вешается системным демоном на `launchd`, пасет бинарники через `WatchPaths` и сам на лету перепатчивает их обратно после каждого фонового обновления `agy` или IDE. Никаких повторных запусков руками.

Байт-сигнатуры и логика взяты из проекта [open-antigravity-patcher](https://github.com/AvenCores/open-antigravity-patcher) от AvenCores, но упакованы в тихий автономный сервис для macOS и Linux без интерактивных зависаний.

---

## Что умеет лечить

Скрипт сам обходит систему и чинит всё, до чего дотянется:

* **Antigravity CLI (`agy`)** — переписывает машинный код проверки региона (ARM64 и x86_64) в Go-бинаре и переподписывает его через `codesign`.
* **Antigravity 2.0 (`language_server`)** — патчит валидатор внутренней авторизации (`hasValidAuth`) в бинарнике внутри `Antigravity.app`.
* **Antigravity IDE (`main.js`)** — выставляет `isGoogleInternal = true` в Electron-бандле и сбрасывает кэш приложения.
* **Плагины под VS Code и Cursor** — глушит в `extension.js` проверку каналов релизов и постоянные попытки перекачать стоковый бинарь поверх пропатченного.

## Установка

Все ставится через симлинки прямо в домашний каталог текущего пользователя (без захардкоженных путей). Если вы подтянете свежие коммиты через `git pull`, в системе всё обновится само:

```bash
git clone git@github.com:petqa/g-patcher.git
cd g-patcher
./install.sh
```

### Что происходит под капотом:
1. В `~/.local/bin/g-patcher` создается симлинк на скрипт (команда сразу доступна в терминале).
2. Скрипт тут же сканирует систему и патчит всё найденное.
3. В macOS поднимается фоновый агент `launchd` (`~/Library/LaunchAgents/com.antigravity.autopatch.plist`). Через механизм ядра `WatchPaths` он отслеживает изменения в `~/.local/bin/agy` и `language_server`. Как только автоапдейтер накатит новую версию и перезапишет файл — демон перепатчит бинарь обратно за 10 миллисекунд.
4. В `~/.zshrc` дописывается короткая функция-страховка на случай, если вы дернули `agy` сразу же после обновления вручную.

## Использование

В повседневной работе руками делать ничего не нужно: сервис работает сам. Но если понадобится проверить статус или запустить точечно:

```bash
# Посмотреть, что найдено в системе и в каком оно состоянии
g-patcher --status

# Принудительно пропатчить все найденные компоненты
g-patcher

# Если файлы лежат в /Applications и требуют прав админа:
sudo g-patcher

# Открыть оригинальное интерактивное TUI-меню из апстрима:
g-patcher -i

# Натравить на конкретный файл или .app:
g-patcher /path/to/agy
g-patcher /Applications/Antigravity.app
```

---

## Удаление

Если захотите полностью снести:

```bash
./uninstall.sh
```

Скрипт выгрузит и сотрет агент `launchd`, снесет симлинки и подчистит записи в `~/.zshrc`.
